How I build with AI

I use coding agents for most of the typing. The planning, the checks and the final call stay with me.

  1. 1

    Spec

    Write the product spec: who it's for, what it must never do, which AI providers are allowed.

  2. 2

    Phase plan

    Split the spec into phases small enough to build and check in one sitting.

  3. 3

    Build with agents

    Pair with Claude Code on one phase at a time, recording decisions as they're made.

  4. 4

    Verify

    Unit and end-to-end tests, accessibility scans, then a check of every change in the running app.

  5. 5

    Review & commit

    I test each phase by hand and commit it myself before the next one starts.
